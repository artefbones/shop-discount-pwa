# Скидка+ — калькулятор скидки и кешбэка

PWA для расчёта суммы после скидки магазина и банковского кешбэка. По умолчанию используется российский рубль и тёмная тема; выбор валюты и темы сохраняется локально. Все вычисления выполняются в браузере.

## Файлы
- `index.html` — интерфейс
- `styles.css` — адаптивный дизайн и светлая/тёмная темы
- `app.js` — расчёты, локальное сохранение настроек, переключение темы
- `manifest.webmanifest` — параметры PWA
- `sw.js` — сервис-воркер и офлайн-кэш
- `icons/` — иконки приложения

## GitHub Pages
Загрузи содержимое этой папки в корень публичного репозитория. Затем открой **Settings → Pages**, выбери **Deploy from a branch**, ветку `main` и папку `/(root)`, нажми **Save**. После публикации открой указанный HTTPS-адрес.

Первый запуск выполняется онлайн, чтобы браузер загрузил файлы и сервис-воркер создал кэш. После этого проверь автономную работу, отключив сеть.
