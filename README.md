# Скидка+ — калькулятор скидки и кешбэка

Небольшое PWA без фреймворков, сборки, сторонних библиотек, рекламы и аналитики. Все расчёты происходят в браузере.

## Возможности

- Цена покупки, скидка 0–100%, кешбэк 0–99%.
- Автоматический пересчёт оплаты после скидки, кешбэка, эффективной цены и общей экономии в деньгах и процентах.
- Кешбэк считается от суммы после магазинной скидки.
- Выбор валюты EUR, USD, RUB, GBP или PLN.
- Последние значения и валюта сохраняются в `localStorage` браузера на текущем устройстве.
- `manifest.webmanifest`, иконки, поддержка добавления на главный экран и service worker с кешированием для офлайн-работы после первой успешной загрузки.
- Все ресурсы локальные; в рабочем приложении нет внешних запросов к библиотекам или API.

## Файлы

- `index.html` — разметка приложения.
- `styles.css` — адаптивный интерфейс.
- `app.js` — вычисления и сохранение значений.
- `manifest.webmanifest` — настройки PWA.
- `sw.js` — кеширование для офлайн-работы.
- `icons/` — иконки приложения.

## Локальный просмотр

Service worker не работает при открытии HTML через `file://`. Используйте локальный HTTP-сервер разработки (например, расширение Live Server в Visual Studio Code) или опубликуйте проект на HTTPS.

## Публикация

Проект подходит для GitHub Pages. При бесплатном тарифе GitHub Free репозиторий для Pages должен быть публичным. Код и сам опубликованный сайт будут доступны в интернете, поэтому не размещайте в репозитории приватные данные.

При изменении кода сохраните файлы, отправьте их в репозиторий и откройте опубликованный сайт онлайн, чтобы браузер получил обновлённые файлы. Затем перезагрузите страницу. Для проверки офлайн-режима сначала загрузите приложение полностью онлайн, после чего отключите интернет и откройте приложение ещё раз.

## Важное о кешбэке

В расчёте кешбэк округляется до двух знаков после запятой и считается от оплаченной после скидки суммы. Реальные банковские условия могут отличаться (округление, лимиты, MCC/категории, исключения и т. п.). Итоговая стоимость — расчётная величина после предполагаемого кешбэка, а не сумма, которую касса спишет сразу.
